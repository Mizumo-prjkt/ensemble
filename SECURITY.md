## Reporting a vulnerability

Ensemble is made with no funding in mind, so there are no bug bounty programs. However, if you still wanted to contribute, sending a bug/vulnerability report on the Issues with detailed explaination helps a lot, even better if you also provided a fix for it.

Note that your submission will be directly studied for any issues, or false flags. Don't take it personally if it's rejected.
